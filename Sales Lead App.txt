	4. Find Leads count(100); 
	5. If N leads are not found: Show less; OR increase radius;
2. The job will start doing the following:
	1. Divide the cordinate+radius into zones of smaller radius. OR divide it in smaller districts
	2. From center to the farthest we will get Business type searches from Various sources.
	3. Remove Duplicates, Add missing info, Clean Data add to DB as per confidence level
	4. Return data to customer and mark these leads as seen by this customer. 
	5. Mark zones as searched for the business type
	6. Add the leads seen by this customer in a table so for next job run we can avoid these leads
3. Search Strategies and sources
	Sources:
	1. Our DB collection
	2. OpenSiteMap	
	3. Google Places API
	4. Website Crawler
	5. Open source website crawler tools(like Airbnb crawler) or some other business website crawler added in future
	6. 
	
	For finding missing details:
	1. Ollama's Web Search (have a token pool)
	2. Other search APIs
	
	Strategy:
	1. Divide the region into subzones
	2. Get the leads user has seen already and find leads in the region that are not seen by user. If exist send these leads and start searching more in this region and parameters to find more leads using other strategies(if all the found leads are seen by user too then mark that place to user as all found for now. try later after some time)
	3. If the leads are not in the DB for the region
		1. Start finding leads for each subzone and divide the leads from each subzone based on popularity so if the region has 1000 leads, and Zone 1 has 400 leads and Zone 2 has 600 leads get 40 leads from zone 1 and 60 from zone 2.
